Pick the Right Container

List, dict, set, tuple — and the dict-key-mutability trap

notes by Karthik ✏️

~ 14 min read ~

Most Python performance bugs you'll meet in your first year aren't algorithmic. They're container choice.

Mental model: shape matches the question
Each container exists because it answers a different question fast.

Move 1 — Pick by access pattern, not by data type

  • Three diagnostic questions, in order: 1. **Do I need uniqueness?** → set 2.
  • 1. English: For each product, count how many distinct customers ordered it.
  • 2. Pick the outer container: We need a count *per product*, looked up by product. That's a dict keyed by product.
  • 3. Pick the inner container: Distinct customers — uniqueness — is a set. defaultdict(set) auto-creates an empty set the first time we touch a key.
  • 4. Compress to the answer: Convert each set to its size for the final report.
  • 5. The diagnostic: Why this shape? Outer dict because we look up by product. Inner set because we deduplicate customers. The shape of the data structure mirrors the shape of the question.

Move 2 — Comprehensions and the unhashable-key trap

  • Comprehensions are the idiomatic way to build all four containers from another iterable. Same shape, different brackets: ```python [x*2 for x in items] # list comprehension {x*2 for x in items} # set comprehension {x: x*2 for x in items} # dict comprehension (x*2 for x in items) # generator expression (lazy) ``` **The trap**: dict keys must be hashable, which means immutable.

Traps to flag for the exam

Takeaways (memorize these)

Pick a container by access pattern, not by data type — uniqueness → set, lookup-by-key → dict, ordered-with-dups → list
`set` and `dict` membership is O(1); `list` and `tuple` are O(n). Wrong container = silent quadratic blow-up
Comprehensions exist for all four shapes — `[]`, `{}` (dict), `{...}` (set), `()` (generator)
Dict keys must be immutable — strings, ints, tuples, frozensets. Use `tuple()` when you need to key on what looks like a list
Reach for `Counter`, `defaultdict`, and `frozenset` from `collections` before reinventing them
