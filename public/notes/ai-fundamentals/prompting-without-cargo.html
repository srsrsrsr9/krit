Mental model: prompts are an API
Treat your prompt like an API contract, not a request to a person. The model is reading patterns; vague phrasing produces vague outputs that match the vagueness.

Move 1 — The 5-part prompt structure

  • Worked example. **Vague prompt:** *Write a customer support reply.* Now with the 5 parts: ``` ROLE: You are a customer support agent for a SaaS company that sells project management tools to teams of 10-200.
  • Bad version: Prompt: 'Classify these emails: billing, technical, sales, refund, other.' Output: ~70% accuracy on a held-out set.
  • + Role + Context: Prompt: 'You are a customer-ops triage agent for a SaaS company. The 5 categories route to different teams.' Adds clarity but minor lift.
  • + Format: Specify: 'Output JSON: {"category": "<one of the 5>", "confidence": 0-1}.' Now machine-parseable. ~75% accuracy.
  • + 3 worked examples: Show 3 representative emails with their correct categories. THIS is where quality jumps to ~92%.
  • + 1 edge case: Show one tricky case and its correct handling. e.g. 'I want to upgrade and have a billing question' — pick *primary* category. ~94% accuracy. Diminishing returns from here.

Move 2 — Few-shot examples are the real cheat code

  • Among the 5 parts, examples are not first among equals — they are the **dominant** lever for structured tasks. - A prompt with no examples gets a generic answer in the most-probable register.

Traps to flag for the exam

The classic trap: the 'just ask nicely' fallacy: Most teams' first prompts look like *'Hi! Could you please write me a really good [thing]? Thank you so much!'*

Takeaways (memorize these)

Prompts are an API — Role + Context + Task + Format + Examples
Examples are the dominant lever for structured tasks; 1-3 well-chosen examples beat all other tricks
One BAD example showing what to avoid is often more useful than a second good example
Cargo-cult phrases ('think step by step', tipping threats) move quality 0-5%; not the lever
Politeness has zero effect on quality; specifications have all the effect
